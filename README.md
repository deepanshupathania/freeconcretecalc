# FreeConcreteCalc

Free concrete calculator for DIY projects.

Calculate bags (60lb/80lb), cubic yards, and cost for slabs, footings, post holes, walls, columns, stairs, and curbs.

**🔗 Live tool:** https://freeconcretecalc.com

## Features

- 8 project types (slab, footing, post hole, wall, column, stairs, curb)
- Multi-zone calculations
- 10% waste factor included
- Cost estimates (bags vs ready-mix)
- PDF export & share link
- Dark mode
- Mobile-friendly
- No signup required
